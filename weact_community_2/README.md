# Закрытый корпус для дисплея WeAct 4.2'

Вариант корпуса от Павла Никитина. Доступны файлы проекта в двух форматах - STL и STEP.

STL файлы сконвертированы после, оригинал проекта в STEP. Небольшой комментарий от автора :

"В качестве АКБ использовал старый пакетик от пауэрбанка на 10000мА/ч, так же добавил солнечную панельку, что в теории может немного поддержать заряд, если будет стоять в районе солнца. В основании места под гайки для утяжеления конструкции.
STP и фото можно выкладывать для желающих отредактировать/повторить."
